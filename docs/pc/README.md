PC 国际服客户端，2026-10-29。容器格式与安卓同源（NKDB / CIDX / `store.cdb` 三者全对得上），
43 类清单**37 类有产物**（族名命中 38，低清族在但块物理缺失），6 类不可交付，差异 10 处，逐条列在实测文档里。

两份实测来自不同区的客户端，容器结论一致，**体量与键数不可混用**。国服那份见 03。

## 一句话差异

| | 安卓 | PC |
| :--- | :--- | :--- |
| 取件方式 | `dd` + `adb pull`（4096 对齐、断批） | 本地按 `.idx` 偏移直读 |
| `saus/raw` 磁盘名 | 明文 | 16 B hash 的 hex |
| `.nab` 语音 | 未验 | 可直接出 `AudioClip` → wav |
| 动态头像框 | 有 | 族不存在 |
| 莱彻 3D | 可出 glb | 无躯干高模 |
| 静态表 | `StaticData.pack` | 无此文件 |

## 复用什么（已由实测确认）

| 部分 | 结论 | 说明 |
| :--- | :--- | :--- |
| NKDB 解密 | ✅ 可直接用 | 魔数、密钥位置、IV 推导、segment_size 全一致 |
| CIDX 解析 | ✅ 可直接用 | 端序小端，记录 28 B，尾部 16 B 忽略 |
| 取件算法 | ✅ 逻辑同，省掉 dd | 三道约束（顺序、长度、不静默跳过）不变 |
| UnityPy 导出 | ✅ 可复用 | 引擎 2021.3.56f2，UnityPy 1.25.4 无需分支 |
| 提取清单 43 类 | ✅ 37 类有产物（族名 38） | 差异 10 处见 01-实测 §3 |
| 落盘与命名 | ✅ 可直接复用 | 与平台无关 |
| 增量判定方法 | ✅ 可直接复用 | 与平台无关 |
