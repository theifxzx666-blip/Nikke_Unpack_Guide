# PC 端拆包（未开始）

本目录尚未实测，内容不是方案，是待办清单。不要拿这里的任何内容当结论使用。

## 现状

安卓端的全链路已经跑通，见 [../android/](../android/)。PC 端只有零散观察，没有系统验证过，因此不写进正文。

写过但未成体系的东西：

- PC 端资源目录不在 `AppData/LocalLow` 下的单一位置，客户端安装目录与用户数据目录分离
- 资源总量与安卓端不同源，不能假设同一版本号的资源内容一致

## 待实测清单

按依赖顺序，前一项不通后面都做不了。

| # | 待验证 | 判据 |
| :-: | :--- | :--- |
| 1 | 资源根目录位置 | 找到 `catalog.db` 或等价的清单文件，确认其在安装目录还是用户数据目录 |
| 2 | 是否使用 chunk 机制 | 是否存在 `store.cdb` 与 `store.cdb.idx` 对应物 |
| 3 | 清单格式是否同源 | 头 4 字节是否为 `NKDB`；否的话记录真实魔数 |
| 4 | CIDX 是否存在 | 若无 idx，取件算法要整体重写 |
| 5 | 资源键命名是否一致 | 抓 50 个键与安卓端比对，看族名与路径规则是否相同 |
| 6 | 加壳情况 | 是否有额外的完整性校验或运行时解密 |
| 7 | 版本号对应关系 | PC 版本号与安卓 `versionName` 是否有一一映射 |
