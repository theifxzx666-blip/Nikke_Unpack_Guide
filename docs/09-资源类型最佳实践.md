# 资源类型提取最佳实践

> 按资源类型给出「判定 → 取件 → 导出 → 验收」的最短路径。前置：已完成场景判定，见 [00-场景矩阵.md](00-场景矩阵.md)。
> 命令默认在仓库根执行，`<...>` 为占位符。

## 0. 通用三步

| 步骤 | 目的 | 子命令 |
| :--- | :--- | :--- |
| 探路 | 确认资源在哪个服、有多少 | `locate` |
| 列键 | 把类名或关键词变成键表 | `find --keys` |
| 取件 | 一个进程搬完整份键表 | `batch` |

```bash
python tools/nk.py locate "<关键词>" --intl-root "<国际服根>" --cn-root "<国服根>"
python tools/nk.py find "<关键词>" --all --keys keys.txt
python tools/nk.py batch keys.txt --scene intl-pc --root "<根>" --bucket dp -o out/ --jobs 4
```

三条通用约束：

- **只认 `(hd)`**：`(sd)` 与 `(hd)` 同名并存，取错的表现是「所有键 0 命中」。
- **先读 4 字节**：`UnityFS` 直读，`NKAB` 才过 NAU；`NAU.exe d -i in/ -o out/` 仅接受目录，空 stdin 可避免挂起。
- **没有自检数字即失败**：贴图看对象数与尺寸，模型看 `ratio ≥ 1.5`，文本看行数。

## 1. 角色立绘

- **适用**：角色或皮肤立绘，用于展示、拼图、并库。
- **键**：`icons-char-full(hd)_assets_c<ID>_<皮肤>_<hash>`，单角色单包。
- **两种产物**：

| 产物 | 源对象 | 规格 | 用途 |
| :--- | :--- | :--- | :--- |
| 紧裁立绘 | Sprite | 尺寸随图，如 405×761 | 展示、并母库「角色立绘」 |
| 原始画布 | Texture2D | 1024²，国服 2048² | 需要完整画布时使用 |

```bash
python tools/nk.py find --scene intl-pc --root "<根>" --bucket dp "c082_00"
python tools/nk.py pull --scene intl-pc --root "<根>" --bucket dp "<完整键>" -o out/full
python tools/nk.py export out/full -o out/png --type image
```

- **验收**：Sprite 尺寸与母库同角色文件一致；Texture2D 长宽为 1024² 或 2048²。
- **注意**：`_uc_tex` 整幅图是 Spine 图集贴图，`00/01/02/03` 是四张不同立绘，不要当拼图块拼接。

## 2. 半身像与 SI 头像

- **适用**：头像、名片、列表小图。
- **键**：半身像 `icons-char-mi(hd)_assets_mi_c<ID>_<皮肤>_s_<hash>`；SI 头像 `icons-char-si(hd)_assets_all_<hash>`，全角色共用一个图集。
- **步骤**：

```bash
python tools/nk.py pull --scene intl-pc --root "<根>" --bucket dp \
    "<icons-char-si(hd)_assets_all_*.bundle>" -o out/si --only "si_c019_00_s"
python tools/get_si.py c019_00
```

- **验收**：SI 为 128×128；`--only` 命中数为 1，不传会导出整个图集。
- **注意**：SI 为独立绘制，不能由半身像裁切还原；图集紧密打包，不能按网格反查归属。

## 3. 头像框

### 3.1 静态

- **适用**：个人主页、名片展示。
- **键**：`icons-user_frame(hd)_assets_all_<hash>`，单图集。
- **取法**：取 **Texture2D**，256×256 整幅；Sprite 为紧密裁切，尺寸不等，与母库规格不符。

### 3.2 动态

- **适用**：单人突击 tier4 等动态档。
- **键**：`icons-dynamic(hd)_assets_all_<hash>`；仅国服，国际服全站零命中。
- **规格**：256×256，每组 31–32 帧。2026-09 版 21 组 / 668 帧；2026-11 版 22 组 / 700 帧（新增 `Queen_DMTR`）。
- **命名**：`dynamic_soloraid_<BOSS>_<代码>_tier4_frame_<NN>.png`，补零两位。

### 3.3 静态与动态统一取件

```bash
python tools/nk.py cnindex --root "<cache 根>" -o build/cn_index.sqlite --jobs 4
python tools/nk.py cnget   --root "<cache 根>" "icons-user_frame(hd)" -o out/frame.bundle
python tools/nk.py cnget   --root "<cache 根>" "icons-dynamic(hd)"   -o out/dyn.bundle
python tools/nk.py export  out/frame.bundle -o out/frames --type image
python tools/nk.py export  out/dyn.bundle   -o out/dyn    --type image
```

### 3.4 GIF 合成

| 项 | 规则 |
| :--- | :--- |
| 帧序 | 按帧号升序，不使用导出顺序 |
| 时长 | 取 AnimationClip 逐帧值；GIF 以 10 ms 为步进，95 ms 会被截成 90 ms |
| 调色板 | 全帧共享 255 色，避免帧间跳色 |
| 透明 | alpha < 128 统一映射到透明索引，`disposal=2` |

- **验收**：尺寸、帧数、总时长三项与源一致；逐帧与基线比对 md5。

## 4. 称号

- **适用**：个人主页称号、条件图标、复制品角标。
- **三类资源不可混为一类**：

| 类型 | 键前缀 | 尺寸 | 说明 |
| :--- | :--- | :--- | :--- |
| 称号横幅 | `usertitle_*` | 308×82 / 256×68 | 可陈列的称号美术 |
| 条件图标 | `icn_usertitle_*` | 64×64 | 无横幅的条件名（新手、说书人、情圣） |
| 角标部件 | `icn_soloraid_museum_sub_title_01_01` | 64×64 | 复制品 R 标，叠加使用 |

- **名称表**：`Locale_System` 的 `USERTITLE_NAME_*`；联盟用独立前缀 `USERTITLE_UNION_RAID_ARENA_RANKING_SEASONn_m`；`usertitle_channel_reservation_reward_<x>` 对应 `USERTITLE_NAME_CHANNEL_<X>`。
- **步骤**：

```bash
python tools/nk.py cnget  --root "<cache 根>" "icons-user_title(hd)" -o out/title.bundle
python tools/nk.py export out/title.bundle -o out/png --type image
```

- **验收**：横幅张数与清单一致；无名称键的条目保留资源名，不自行拟定译名。
- **注意**：换版判定不能用 md5——同一资产重新打包后 md5 全变（235 张样本实测全不同、内容一致）。改用可见区平均像素差，阈值 12。

## 5. Spine 与 3D 模型

- **适用**：角色待机/战斗、敌人立绘、BOSS 模型、大厅动画。
- **键**：`spinestandingcharactergroup(hd)`、`spinecombatcharactergroup(hd)`、`spinemonstergroup(hd)`、`spinestandingprefabgroup(hd)`（均在 `dp`）；`spotmonster(hd|sd)_<型号>`（在 `core`）。
- **步骤**：

```bash
python tools/nk.py batch  keys.txt --scene intl-pc --root "<根>" --bucket dp -o out/spine --jobs 4
python tools/nk.py export out/spine -o out/spine --type spine

python tools/nk.py batch  keys.txt --scene intl-pc --root "<根>" --bucket core -o out/model --jobs 4
python tools/nk.py export out/model -o out/glb --type model
```

- **验收**：模型输出 `objects / triangles / vertices / ratio`，要求 `ratio ≥ 1.5`；Spine 输出 `skel + atlas + png`。
- **注意**：
  - Spine 运行时只认大版本，4.1.20 与 4.0.47 需两套播放器，不可混用。
  - 按 atlas `bounds` 硬拼图集必然得到碎片。
  - 模型子网格材质必须按 `m_SubMeshes` 与 `m_Materials` 的下标对应，只取第 0 个会让多数顶点用错贴图。
  - 阶段归属按 `_var` 变体根判定，不按节点名。

## 6. 剧情插画与场景

- **适用**：主线/活动插画、场景背景、地图。
- **键**：`scenariobackground(hd)_assets_eventscene_<活动或章>_<序>_<hash>`、`spotbackground(hd|sd)_assets_sbg_<场景>`。
- **步骤**：`find --keys` 命中后直接 `batch`，`export --type image`。
- **验收**：按章统计键数，与包内 Texture2D 数量一致。
- **注意**：装配型 `spotbackground` 需要还原装配再渲染；判定「该章只有一张」必须交叉核对同族键、动画包与三个桶。

## 7. UI 图集与图标

- **适用**：技能图标、活动 UI、卡池与商店素材。
- **键**：`icons-skill(hd)_assets_all_<hash>`、`eventui-<代号>_assets_*`、`gachaui*`、`contentsshopsprite`。
- **步骤**：

```bash
python tools/nk.py batch keys.txt --scene intl-pc --root "<根>" --bucket dp -o out/ui \
    --only "<关键词1>,<关键词2>" --jobs 4
```

- **验收**：对象数、导出张数、体积三项对齐预期。
- **注意**：`sactx-*` 是图集分页，不作为独立产物；活动 UI 与公共元素共包，实测 22 个包 23,578 个对象中仅 508 个属于该活动，不加白名单会多写出 180 张无关图片。

## 8. 文本表

- **适用**：剧情、技能描述、称号名、活动文案。
- **载体**：国服 `.lss` 为明文 SQLite；国际服 `.lsc` 为 NKDB 加密；两平台文本层发布同一份。
- **步骤**：

```bash
export MSYS_NO_PATHCONV=1
D=/sdcard/Android/data/com.tencent.nikke/files
adb pull "$D/saus/saus/lss/Locale_System.lss" build/cn/Locale_System.lss
sqlite3 build/cn/Locale_System.lss \
  "select Key,[zh-CN] from Locale_System where Key like 'USERTITLE_NAME_%' limit 5"
```

- **验收**：`Locale_System` 为 10,670 行 / 4,362,240 B；行数偏差说明取到别的版本。
- **注意**：活动剧情须同时查 `Locale_MainScenario` 与 `Locale_SubScenario`，只查前者会漏掉多章式活动；称号名只在 `Locale_System`。

## 9. 静态表

- **适用**：关卡、奖励、任务、增益等数值表。
- **链路**：lobby API → `pack` + `salt1/salt2` → 双层 AES → `mpk` → JSON。
- **步骤**：`tmp_fetch_staticdata_info.py` → `tmp_unpack_staticdata.py` → `tmp_mpk2json.py` → `tmp_staticdata_manifest.py`，不在 `nk.py` 内。
- **验收**：153 快照解出 654 张表、残余 0。
- **注意**：客户端内不含该文件；判定「数据拿不到」之前必须先翻静态表。

## 10. 音频与视频

- **适用**：BGM、台词配音、过场视频。

**音频**

- `.nab` 是 bundle 的外层后缀，内部为标准 AudioClip，可直接输出 wav（48 kHz / 16 bit）。
- 一个包可能含 93 个 clip，按包计数会严重低估语音量。

```bash
python tools/nk.py batch  keys.txt --scene intl-pc --root "<根>" --bucket ja -o out/voice --jobs 4
python tools/nk.py export out/voice -o out/wav --type audio
```

**视频**

- 裸 mp4，整文件读取，无需解密；国服在 `saus/saus/movies/`，国际服在 `com.shiftup.patch/saus/raw/<32hex>.mp4`。

```bash
export MSYS_NO_PATHCONV=1
adb pull "/sdcard/Android/data/com.tencent.nikke/files/saus/saus/movies" out/movies
```

- **验收**：音频按 clip 数统计；视频校验文件头与时长。

## 11. 失败对照

| 症状 | 根因 | 处置 |
| :--- | :--- | :--- |
| 所有键 0 命中 | 取了 `(sd)` 或键名带 hash | 改用族名检索，只认 `(hd)` |
| 导出图全黑或空白 | 取到 `sactx-` 图集页或空 Sprite | 过滤 `sactx-`，核对对象数 |
| 模型导出后不动 | 动画绑定了另一阶段骨架 | 按 `_var` 根判定阶段 |
| 模型贴图错乱 | 只取 `m_Materials[0]` | 按下标与 `m_SubMeshes` 对应 |
| 静态表查不到 | 在客户端里找 | 走 lobby API 链路 |
| 换版后 md5 全变 | 解码差异，非内容变更 | 改用像素差阈值判定 |
| UnityPy 段错误 | 个别毒包 | 进程隔离，分片 subprocess |
| 取件数少于键数 | 键表被 strip 或 `#` 注释吞行 | 仅识别 `# ` 注释，保留前导空格 |

## 12. 最小代码

```python
import UnityPy

env = UnityPy.load("x.bundle")
for obj in env.objects:
    if obj.type.name not in ("Texture2D", "Sprite"):
        continue
    data = obj.read()
    data.image.save(f"out/{data.m_Name}.png")
```

```python
# GIF 时长以 10 ms 为单位，按厘秒分配可避免累计截断
def durations(total_ms, n):
    base, rem = divmod(total_ms // 10, n)
    return [(base + (1 if i < rem else 0)) * 10 for i in range(n)]
```
